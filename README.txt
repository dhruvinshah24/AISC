DEPENDENCIES

Install the required libraries with:

pip install numpy matplotlib scikit-learn scikit-fuzzy

NOTES

All Python files have been kept free of code comments.
Experiment 10 contains an illustrative sample dataset for demonstrating the ANFIS training process. It is not a real-world validated AQI model. Replace the sample readings and AQI targets with a properly sourced dataset for actual prediction.
